# Clickbandit — Clickjacking Evidence

Clickbandit is Burp Suite's built-in clickjacking PoC generator
(Burp menu → **Burp Clickbandit**). Evidence here must come from a real
recording session.

## How to record

1. In Burp, open **Burp Clickbandit** and click **Copy Clickbandit to
   clipboard**.
2. In the browser, log in to DVWA (`http://127.0.0.1:4280`, security
   Low) and navigate to the page to attack (e.g. the CSRF module).
3. Open DevTools → Console, paste the Clickbandit script, press Enter.
   The page reloads inside the Clickbandit recorder.
4. Click **Start**, then click the target button(s) (e.g. **Change**).
   Click **Finish** → **Review attack**.
5. Save the generated PoC: Clickbandit offers the recorded attack as a
   standalone HTML/iframe payload — save it into `recordings/`.
6. Re-run the saved PoC to confirm the hidden click reproduces.

Note: DVWA sends no X-Frame-Options/CSP frame-ancestors, so it is
frameable and Clickbandit works against it directly.

Edition note: Clickbandit is available in Burp Suite Community Edition.
The comment "Clickjacking PoC Generated by Burp Suite Professional"
inside the generated HTML is fixed template text in Clickbandit's
client-side script and appears regardless of the installed edition.

## What to save where

- `recordings/` — the Clickbandit-generated PoC HTML / payload.
- `screenshots/` — the recorder overlay, the recorded click sequence,
  and the replayed attack result.

Reference the saved filenames in `../report/evaluation-matrix.md` once
captured.
